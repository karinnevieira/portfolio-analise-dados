# 🎵 Análise dos fatores de sucesso musical no Spotify

---

## 📌 Objetivo

Identificar quais fatores contribuem para o sucesso de uma música, medido tanto pelo
número de reproduções quanto pela presença nos charts.

O dashboard foi desenvolvido para gerar insights sob a ótica do **artista** e da
**indústria musical**, respondendo a uma pergunta central:

> _O que faz uma música dominar o mundo?_

---

## 🛠️ Habilidades Aplicadas

- 🗃️ SQL (Google BigQuery)
- 📊 Looker Studio
- 🧹 Limpeza e tratamento de dados
- 📈 Análise de correlação
- 📖 Data storytelling
- 🔄 Metodologia ágil (Scrum)

---

## 🔍 Principais Conclusões

**🎧 Playlists são a alavanca mais poderosa**
Correlação de 0,79 com o número de reproduções. O pitch via Spotify for Artists
deve ser prioridade no lançamento.

**📅 Julho é o mês mais estratégico para lançamentos**
Maior média de entrada nos charts — lançamentos devem considerar o apelo
do verão no hemisfério norte.

**📵 Shazam não prediz hits**
Correlação de apenas 0,02 com streams. A descoberta musical migrou para
dentro das plataformas, via algoritmos e playlists curadas.
